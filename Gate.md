# What's New in GATE CSE 2027

## Digital Logic

Added clearer emphasis on:

- Algebraic minimization
- Karnaugh Maps
- Tabular minimization
- Design of combinational circuits
- Design of sequential circuits

---

## Computer Organization & Architecture

Added:

- Hardwired control unit
- Microprogrammed control unit
- Memory interfacing
- Cache mapping
- Memory hierarchy performance

Reduced emphasis on:

- Main memory
- Secondary storage

---

## Computer Networks

### Removed

- OSI Stack
- TCP/IP Stack
- Framing
- Ethernet Bridging
- ARP
- DHCP
- ICMP
- UDP
- SMTP
- FTP
- Email
- Shortest-path routing
- Flooding routing

### Retained

- Layering principles
- Error detection
- MAC
- Distance Vector routing
- Link State routing
- IPv4
- CIDR
- NAT
- TCP Flow Control
- TCP Congestion Control
- Socket API

Application Layer now includes only:

- DNS
- HTTP
