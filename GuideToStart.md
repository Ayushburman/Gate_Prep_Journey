## 2. Syllabus

### 2.1 General Aptitude

> 15 marks — Common to all GATE papers

**Verbal Ability**
- English grammar: tenses, articles, adjectives, prepositions, conjunctions, verb-noun agreement
- Vocabulary: words, idioms, and phrases in context
- Reading comprehension
- Narrative sequencing

**Quantitative Aptitude**
- Data interpretation: bar graphs, pie charts, 2D/3D plots, maps, tables
- Numerical computation and estimation: ratios, percentages, powers, exponents, logarithms
- Permutations, combinations, series
- Mensuration and geometry
- Elementary statistics and probability

**Analytical Aptitude**
- Logic: deduction and induction
- Analogy
- Numerical relations and reasoning

---

### 2.2 Engineering Mathematics

**Discrete Mathematics**
- Propositional and first-order logic
- Sets, relations, functions, partial orders, lattices, monoids, groups
- Graphs: connectivity, matching, coloring
- Combinatorics: counting, recurrence relations, generating functions

**Linear Algebra**
- Matrices, determinants, systems of linear equations
- Eigenvalues and eigenvectors
- LU decomposition

**Calculus**
- Limits, continuity, differentiability
- Maxima and minima
- Mean value theorem
- Integration

**Probability & Statistics**
- Random variables
- Standard distributions: uniform, normal, exponential, Poisson, binomial
- Mean, median, mode, standard deviation
- Conditional probability and Bayes theorem

---

### 2.3 Digital Logic

- Boolean algebra
- Combinational and sequential circuits
- Minimization techniques
- Number representations and computer arithmetic (fixed and floating point)

---

### 2.4 Computer Organization & Architecture

- Machine instructions and addressing modes
- ALU, datapath, control unit
- Instruction pipelining and hazards
- Memory hierarchy: cache, main memory, secondary storage
- I/O interface: interrupt mode and DMA mode

---

### 2.5 Programming & Data Structures

- Programming in C
- Recursion
- Arrays, stacks, queues, linked lists
- Trees, binary search trees, binary heaps
- Graphs

---

### 2.6 Algorithms

- Searching, sorting, hashing
- Asymptotic worst-case time and space complexity
- Algorithm design techniques: greedy, dynamic programming, divide-and-conquer
- Graph algorithms: traversals, minimum spanning trees, shortest paths

---

### 2.7 Theory of Computation

- Regular expressions and finite automata
- Context-free grammars and pushdown automata
- Regular and context-free languages, pumping lemma
- Turing machines and undecidability

---

### 2.8 Compiler Design

- Lexical analysis, parsing, syntax-directed translation
- Runtime environments
- Intermediate code generation
- Local optimization
- Data flow analyses: constant propagation, liveness analysis, common subexpression elimination

---

### 2.9 Operating Systems

- System calls, processes, threads
- Inter-process communication, concurrency, synchronization
- Deadlock
- CPU and I/O scheduling
- Memory management, virtual memory
- File systems

---

### 2.10 Databases

- ER model
- Relational model: relational algebra, tuple calculus, SQL
- Integrity constraints, normal forms
- File organization, indexing: B trees and B+ trees
- Transactions and concurrency control

---

### 2.11 Computer Networks

- Concept of layering: OSI and TCP/IP protocol stacks
- Packet, circuit, and virtual circuit switching
- Data link layer: framing, error detection, medium access control, Ethernet bridging
- Routing protocols: shortest path, flooding, distance vector, link state
- Fragmentation, IP addressing: IPv4, CIDR notation
- IP support protocols: ARP, DHCP, ICMP
- Network Address Translation (NAT)
- Transport layer: flow control, congestion control, UDP, TCP, sockets
- Application layer protocols: DNS, SMTP, HTTP, FTP, Email

## 4. Study Timeline

### Month 1 — Foundation: Mathematics & Logic

**Focus:** Build the mathematical base that underpins all core CS subjects

| Topic | Notes |
|---|---|
| Basic Arithmetic & Algebra | Ratios, percentages, exponents |
| Geometry & Trigonometry | Mensuration, coordinate geometry |
| Functions, Graphs & Logarithms | Domain, range, log rules |
| Sets & Relations | Partial orders, lattices |
| Propositional Logic | Predicates, quantifiers |
| Digital Logic — Boolean Algebra | Gates, minimization basics |

---

### Month 2 — Core Math: Linear Algebra & Calculus

**Focus:** Complete Engineering Mathematics; begin COA foundation

| Topic | Notes |
|---|---|
| Calculus | Differentiation, integration, mean value theorem |
| Linear Algebra | Matrices, eigenvalues, LU decomposition |
| Differential Equations | Basic ODEs |
| Probability & Statistics | Distributions, Bayes theorem |
| COA Basics | Datapath, ALU, addressing modes |

---

### Month 3 — Discrete Math + Theory Subjects

**Focus:** Complete Discrete Math; begin Theory of Computation and Compiler Design

| Topic | Notes |
|---|---|
| Graph Theory | Connectivity, matching, coloring |
| Combinatorics | Counting, recurrence, generating functions |
| Finite Automata | DFA, NFA construction |
| Regular Expressions | Kleene's theorem |
| Context-Free Grammars | Derivations, parse trees |
| Pushdown Automata | NPDA, DPDA |
| Turing Machines | Decidability and undecidability |

---

### Month 4 — Programming, DSA & Algorithms

**Focus:** Data structures and algorithm design — high-weightage section

| Topic | Notes |
|---|---|
| C Programming & Recursion | Pointers, function calls, recursion tree |
| Arrays, Stacks, Queues | Implementation and complexity |
| Linked Lists, Trees, Heaps | Traversals, operations |
| Graphs & BST | DFS, BFS, insertion/deletion |
| Sorting & Searching | QuickSort, MergeSort, binary search |
| Greedy, DP, Divide & Conquer | Knapsack, Fibonacci, MST |
| Graph Algorithms | Dijkstra, Bellman-Ford, Kruskal, Prim |

---

### Month 5 — Systems: OS, DBMS & Compiler Design

**Focus:** High-yield systems subjects with PYQ practice

| Topic | Notes |
|---|---|
| Processes & Threads | PCB, context switching |
| Scheduling & Deadlock | Banker's algorithm, scheduling criteria |
| Virtual Memory | Paging, segmentation, page replacement |
| SQL & Relational Algebra | Joins, aggregation, views |
| Normalization & B+ Trees | 1NF through BCNF, tree operations |
| Transactions | ACID, serializability, concurrency control |
| Lexical Analysis & Parsing | Tokens, LL(1), LR(0), SLR, LALR |
| Intermediate Code & Optimization | Three-address code, data flow analysis |

---

### Month 6 — Computer Networks + COA Deep Dive

**Focus:** Complete networks; consolidate COA with pipelining and memory hierarchy

| Topic | Notes |
|---|---|
| OSI & TCP/IP Layers | Protocol mapping |
| Routing Protocols | Distance vector, link state |
| TCP/UDP & Congestion Control | Sliding window, TCP congestion |
| IP Addressing & NAT | Subnetting, CIDR, ARP, DHCP |
| Instruction Pipelining | Hazards: structural, data, control |
| Cache & Memory Hierarchy | Direct/set-associative/fully-associative |
| I/O — DMA & Interrupt | Polling vs interrupt vs DMA |

---

### Month 7–8 — Revision + Full-Length Mock Tests

**Focus:** Comprehensive revision, PYQ solving, and timed mock exams

| Activity | Detail |
|---|---|
| PYQ — All Sections | Minimum 3 years of previous papers |
| Full-Length Mocks | Timed, exam-condition practice |
| Weak Area Targeting | Re-study topics with low accuracy |
| GA — Aptitude Drills | Daily 10-question practice |
| Formula Revision Sheets | One-page summaries per section |
